# ForgeVideo

A deliberately tiny macOS video editor for Matt Katyella. Vue 3 + TypeScript + Pinia + Tailwind in a
Tauri 2 shell; Rust backend drives `ffmpeg`/`ffprobe` as subprocesses. Editing never touches media:
the timeline is metadata (integer milliseconds) and only Export renders.

## Commands

Setup once, in order: install Homebrew → `brew install ffmpeg` (the app spawns the `ffmpeg`/`ffprobe` CLIs and
asks for `h264_videotoolbox`; nothing works without them) → `xcode-select --install` → Rust via rustup → Node 20+ →
`npm install`. Full steps and verification commands are in README.md.

```sh
npm run tauri dev                       # run the app
npm test                                # vitest: utils, types, API wrapper, store, every component, App shell
npm run test:watch                      # vitest in watch mode
npm run test:coverage                   # same, with v8 coverage
npm run build                           # vue-tsc type check (includes tests) + vite build
cd src-tauri && cargo test              # Rust unit tests + tests/export_e2e.rs (spawns real ffmpeg)
npm test && npm run build && (cd src-tauri && cargo test)   # everything
```

Non-login shells need `source ~/.cargo/env` before `cargo`. Run all three checks before reporting work done.

## Supported features (V1)

Media pool (the library column left of the preview, under Pinned loops; `App.vue` mounts both)
- Every imported file lives in the pool (`Project.pool`) with tabs All / Clips / Audio / Images, grid or list view (persisted in localStorage). **Import…**, **⌘I** and OS drag-and-drop add to the pool; video also lands on V1. Pointer-drag (never HTML5 DnD) a pool item onto a track, or double-click to place it at the playhead. The same file (compared by canonical path) is never pooled twice, and `project_open` re-probes the pool so stale `MediaInfo` (e.g. an mp3 whose cover art once read as video) is corrected. whisper segments with no letters or digits (`♪ ♪`, `[Music]`) are dropped, and the panel says "Transcribed, but no speech was found" when a transcript exists with no cues. `probe.rs` ignores cover-art streams and treats MJPEG with a duration as video. `Banner.vue` shows `store.notify(...)` for a few seconds: duplicate imports, audio dropped on a video row, video/images dropped on an audio row, audio dropped with no audio track, and Finder drops that land on the timeline (they still go to the pool).

V1 video track (`Project.clips`)
- Any video ffmpeg decodes (extension list in `src/utils/media.ts`: mp4, mov, m4v, mkv, webm, avi, mts, m2ts, 3gp, ts, mpg, mpeg, wmv, flv, mxf) **or a still image** (png/jpeg/webp/bmp/tiff; 5 s by default, trim to any length, rendered via `-loop 1 -t`, silent, previewed with a wall-clock instead of a `<video>`). Contiguous, ripple-edited.
- **Trim** in/out points by dragging clip edges (frame-snapped, min clip 100 ms), rippling everything after.
- **Split** the selected clip at the playhead (**⌘T**); left half keeps its id, fades/transition move to the right ends. Works for V2 and audio clips too.
- **Merge** (⇧-click two or more clips on one row, **⌘J** or right-click → Merge N clips): `timeline::merge` via the one `clip_merge(ids)` command, any row. Pieces must be neighbours from the same file with `source_end == next.source_start` (stills: same file only) and, on overlay/audio rows, touching on the timeline. The first piece keeps its id/name/fade-in; the last supplies fade-out (and the V1 transition). The store holds the primary `selected` plus `extraSelected` (same row only); `selectedAll` drives highlighting and the menu. The Inspector shows a **Join N clips (⌘J)** button under Split at playhead for V1, overlay and audio clips once two or more are selected (never titles).
- **Delete** (**⌫**) and **reorder** by dragging a clip past its neighbour's midpoint. The timeline is always contiguous.
- **Fade in / fade out** per clip (video + audio), capped at 5 s or the clip length.
- **Transitions** between clips: Cut, **Cross dissolve**, **Dip to black** (100–3000 ms, clamped to half the shorter neighbour; the last clip never has one).
- **Split audio from video** (right-click a V1 clip): `timeline::detach_audio` copies the clip's range, volume and fades to an `AudioClip` on the first audio track (created if none) and mutes the video clip.
- **Rename** (right-click any clip on any track → Rename…): `name: Option<String>` on `Clip` / `OverlayClip` / `AudioClip`, set by the one `clip_rename` command (`timeline::rename`, trimmed, ≤ 80 chars, blank = file name). Splits and detached audio keep the name; display goes through `clipName()` in `src/types/project.ts`.
- **Volume** per clip (0–200 %) and **mute**, plus a track-level mute (`Project.video_muted`, speaker icon in the V1 gutter) that silences every V1 clip and a track fader (`Project.video_volume`, 0–1, range input under the V1 label) multiplied into every clip's volume on export and in the preview.

Overlay layers V2, V3, … (`Project.overlays`, `Project.overlay_layers`)
- Any number of overlay rows for composite shots; each `OverlayClip.layer` picks its row and higher layers composite on top. Free-positioned clips: video or stills (default 5 s, stretch by trimming). A video overlay's soundtrack is heard: per-clip `volume` (0–2) + `muted` (`overlay_set_audio`, Inspector) and a per-row mute + 0–1 fader in `Project.overlay_audio[layer]` (`overlay_layer_set_audio`, gutter). Export mixes audible overlays into the same `amix` as audio tracks (the overlay's opacity fades double as audio fades; audio-only export keeps heard overlays); the preview plays them at clip × row gain. Files saved before overlays carried sound have no `muted` field and load muted. No overlap within a layer (a placed clip pushes what it lands on), no transitions. The gutter's single **+ Track** button opens a menu (Video / Audio / Music / Narration / SFX): Video adds an overlay row (labelled V2, V3, … · video), the rest add an audio track with that label; ✕ removes a row and its clips. Per-clip opacity fades, a constant **opacity** 0–1 (`overlay_set_opacity`, Inspector slider; `colorchannelmixer=aa=` in the RGBA stage, multiplied with the fades in the preview) and a `Placement` (width as a fraction of the frame + centre); stills default to a 35 % bottom-right badge, video to full frame. Drag / scroll-wheel the selected overlay in the preview. Overlays that start after V1 ends are ignored on export.

Text rows T1, T2, … (`Project.texts`, `Project.text_layers`)
- Rows of titles at the top of the timeline (`TextClip`: `layer` (0 = T1), `style`, `timeline_start`, `duration`, fades, normalised centre `x`/`y`). **+ Track → Text** adds a row (`text_layer_add`), ✕ in the gutter removes it and its titles (`text_layer_remove`, higher rows renumber, the last row stays); `text_add`/`text_move` take the layer and a title can be dragged between rows. Each row's **+ Text** adds a 5 s "Title" at the playhead and selects it; drag to move in time, either edge trims the length, ⌘T splits (keeps the row), ⌫ or right-click → Delete removes, Rename works, Merge never applies. Titles push each other apart within a row only (`relayout` sorts by `(layer, start)` and grows `text_layers` to fit); higher rows composite on top, in the preview and on export. Files saved before text rows load everything on T1. The Inspector's **Title** section edits the whole `TextStyle` in one `text_set_style` call: multi-line text (Enter = new line, ≤ 500 chars), **any installed font** (`system_fonts` runs `fc-list : family`, bundled Quicksand/Orbit first, a fixed macOS list if fontconfig is missing), size 2–40 % of the frame height, `#rrggbb` colour via `<input type=color>` (the macOS colour panel), and an optional **Backdrop** (rounded rectangle, any colour, 0–1 opacity). Drag the selected title in the preview to place it, scroll to resize.
- **ffmpeg here has no `drawtext`** (Homebrew build without freetype), so titles are rasterised by the webview: `src/utils/textRaster.ts` draws the style to a transparent PNG with `<canvas>` (font px = size × frame height, padding/radius 0.45 em, cached by style + size). The preview shows that raster at preview size; on export `ExportDialog` calls `store.textRasters(w, h)` at the output size and `export_start(settings, texts)` writes the base64 PNGs to `$TMPDIR/forgevideo-<job>/`, `plan_with_texts` feeds them to `graph::text_chain` (looped `-loop 1 -t`, `format=rgba`, alpha fades, no scale) composited **after every overlay layer**, and the dir is removed when ffmpeg ends. A title inside the V1 span with no raster refuses to start ("text clip was not rendered"); titles after V1 ends are ignored; audio-only exports skip them. Any title inside V1 blocks stream copy ("text track"). `build_short` does not carry titles over.

Audio tracks (`Project.audio_tracks`)
- Any number of labelled tracks (Music / SFX / Narration / Other, free text) with free-positioned clips (mp3/m4a/aac/wav/aiff/aif/flac/ogg/oga/opus/caf/m4b/wma or the audio of a video): volume, fade in/out, mute per clip, mute and a 0–1 fader per track (`AudioTrack.volume`, gutter range input; `audio_track_update` takes label, muted and volume together). Every mute control is the `MuteToggle` speaker icon: green = audio on, grey struck-through = muted. Mixed under V1 audio with `amix` and trimmed to the video length on export. v1 project files with a `music` bed load as one "Music" track.

Range selection & pinned loops (`Project.loops`)
- **Drag on the ruler** selects a time range (a plain click still scrubs; a click outside the range clears it, Esc too). The range is a yellow band over every row with a solid strip and two `cursor-ew-resize` handles on the ruler; edges snap to clip boundaries and the playhead. Session-only store state: `range`, `loopOn`, `activeLoopId` (`setRange`, `selectLoop`, `playRange`); `loopRange` is what `Preview.vue` wraps on (both the still wall-clock and the `<video>` tick jump back to `range.start`, and starting playback outside the range starts at its start). Toolbar: **⟳ Loop** (or **L**), **Pin**, ✕.
- **Pinned loops** (`Loop { id, name, start, end }`, `loop_add(name, start, end)` / `loop_remove(id)`; a blank name becomes `m:ss–m:ss`) live in the project file and are listed in `LoopsDrawer.vue` at the top of the library column left of the preview, above the media pool (`store.loopsOpen` persisted in localStorage): ▶/❚❚ plays the loop on repeat, the name selects it (yellow on the timeline), **Export** opens the Export dialog on it (`store.exportLoop` → `store.exportOpen`, which now owns the dialog), ✕ unpins, double-click the name to rename (`loop_rename`, blank = the span). The same range cannot be pinned twice: the store shows "Already pinned as “name”" and selects that loop, and Rust's `loop_add` refuses it too. Like highlights, loops are fixed in timeline time: `relayout` clamps them to V1 and drops any shorter than 100 ms.
- AI highlight cards carry **▶** (`playRange` over the highlight span, again = pause) and **Pin loop** (`loopAdd(title, span)`, "Pinned" once a loop with that span exists) next to **Export short**; **Show** also selects the span. Pinning or picking a loop bumps `store.revealRange` and `Timeline.vue` scrolls so the range starts 40 px inside the view (no jump when already visible).
- Layout: `store.aiOpen` owns the ✦ AI toggle; the green highlight bands render only while it is on (highlights stay in the project). `store.libraryWidth` (200 px – half the window) and `store.loopsHeight` (60 px – 60 % of the window) are the two library splitters in `App.vue` (`library-resize`, `loops-resize`); `store.inspectorWidth` (240 px – half the window, `inspector-resize` left of the Inspector / AI panel) sizes the right column. All persisted in localStorage like `timelineHeight`.

Output
- Aspect presets: **YouTube 16:9** 1920×1080, **Shorts/Reels 9:16** 1080×1920, **Square 1:1** 1080×1080, **LinkedIn 4:5** 1080×1350.
- **Reposition/zoom** the source inside the preset (drag / scroll-wheel in the preview, or the Inspector's **Zoom** slider −100 … 0 … +100 ↔ `Crop.scale` 0.25 … 1 … 4, `zoomToScale`/`scaleToZoom`). Zoomed in, the frame is a crop of the source (clamped inside it); **zoomed out** (`scale < 1`) the source shrinks onto black and `x`/`y` are not clamped, so it can sit partly outside the frame (`crop_scale_filter` emits `scale,pad,crop`; the preview mirrors it). Rotated phone footage uses its display size.
- Preview mirrors the export's crop math, fades and dissolve opacity; media WebKit cannot play (mkv, avi, mts…) raises a banner instead of freezing playback; **Space** play/pause, **←/→** frame nudge (**⇧** = 1 s), **Home/End**.
- **Help**: **Help** in the top bar opens `HelpDialog.vue` as an in-app guide: a section nav (`GUIDE`, one entry per part of the app: overview, project, media pool, V1, overlays, text rows, audio, range & loops, preview, AI mode, export) and a last **Keyboard & mouse** section; the **?** button (or the **?** key) opens the same dialog on that section (`section` prop = `SHORTCUTS_SECTION`). `SHORTCUTS` / `MOUSE` there are the single source; README's Keys table mirrors it. Keep `GUIDE` in step when a feature changes.

Export (**⌘E**)
- **Stream copy** (`-c copy`, instant, keyframe-snapped) when a single untouched h264/hevc clip already matches the preset.
- Otherwise **hardware encode** via `h264_videotoolbox` (Draft 4 / Standard 10 / High 18 Mbit/s at 1080p, scaled by pixel count) + AAC 192k, `+faststart`. The dialog lists why a re-encode was needed.
- **Audio only** (.m4a AAC) for podcasts.
- **Range** (`ExportSettings.range: Option<Range>`): when a range is selected the dialog preselects **Range · <loop name>** (flip back to **Whole timeline**); the planner's `export_span` clamps it to V1, forces a re-encode (reason "range") and sets `duration_ms` to the span, `graph.rs` cuts the finished graph with `trim/atrim start:end` + `setpts=PTS-STARTPTS` (every `enable=between` above stays in timeline time), and `ai::captions::crop_cues` crops and re-times the `.srt`. The default filename gets ` - <name>`.
- Progress bar, elapsed time, cancel (kills ffmpeg and removes the partial file), Reveal in Finder.

Project
- **Undo / redo** (**⌘Z** / **⇧⌘Z**, Ctrl works too): the store keeps up to 100 pre-edit snapshots (`undoStack` / `redoStack`, filled by `apply()` whenever an edit marks the project dirty, cleared by New / Open / load). `undo()` hands the snapshot to the one `project_restore` command, which relayouts and stores it; the undone state goes on the redo stack. Session-only, never saved.
- New / Open / Save (**⌘S**, **⇧⌘S** save-as) as pretty JSON `.forgevideo`. The last saved / opened path is kept in localStorage (`forgevideo.lastProject`, `store.lastProjectPath`): launch reopens it when it still loads (otherwise it is forgotten and the blank project shows), New forgets it, and the Open / Save dialogs start in its folder. Media paths inside the project folder are stored relative. Loading relayouts and clamps stale data. Unsaved-changes prompt on New/Open.
- Thumbnail filmstrips (≈40 JPEGs per source) and waveform peaks (1 byte / 10 ms) cached in `~/Library/Caches/ForgeVideo/<key>/`, keyed by path + size + mtime.

AI mode (**✦ AI** toolbar button, `AiPanel.vue` takes the Inspector's place)
- Runs on the user's own tools, no API key: `whisper-cli` (Homebrew `whisper.cpp`) + a ggml model for speech, the **Claude Code CLI** (`claude -p`, the user's login) for picks. `ai_status` reports what is missing plus the signed-in Claude `account` (from `claude auth status --json`); lookups honour `FORGE_WHISPER`, `FORGE_WHISPER_MODEL`, `FORGE_CLAUDE`. `scripts/install-ai.sh` (bundled as the `install-ai.sh` resource, `target/debug/` in dev) installs Homebrew, ffmpeg, whisper.cpp, the model and Claude Code idempotently; the panel's **Install AI tools…** (`ai_install`) opens it in Terminal.app and polls `ai_status` every 3 s until whisper, model and Claude Code exist. The panel's **Sign in to Claude** (`ai_claude_login`) opens Terminal.app on `claude auth login` via osascript and the store polls `ai_status` every 2 s until an account appears; **Sign out** is `ai_claude_logout`. Highlights are gated on `account`, not just the binary. **First launch**: `WelcomeDialog.vue` opens over the editor until it is finished or skipped (`forgevideo.welcomed` in localStorage): step 1 runs the same **Install AI tools…** flow, step 2 the same **Sign in to Claude** flow; shortcuts are paused while it is up, and nothing about the account is stored by the app (Claude Code keeps the login). Claude is started with no tools, no MCP servers and no session file, in the temp dir, and only ever receives transcript text on stdin.
- **Captions**: `ai_transcribe` (job kind `transcribe`) transcribes every V1 source that has speech; the result is cached as `transcript.json` next to the thumbs. `Project.transcripts` holds cues in **source time**; the caption row under V1, the preview caption and the `.srt` are all derived by `ai::captions::timeline_cues` (twin: `src/utils/captions.ts`), so edits to V1 never desync them. Double-click a caption to correct it (`cue_set_text`, blank removes it). **Copy** in the panel puts the transcript on the clipboard as plain text, one cue per line (`transcriptText`, `api.copyText` → the clipboard-manager plugin, `clipboard-manager:allow-write-text`). The caption row only exists when there are cues. Click the CC label or the row to select the captions track (`Selection { kind: "captions" }`): the Inspector shows a Captions section with an on/off switch (`Project.captions_enabled`, `project_set_captions_enabled`); off dims the row, hides the preview caption (`currentCue` is null) and export writes no `.srt`. ⌫ never deletes it. Export writes `<name>.srt` beside the file; captions are **not** burned into the video.
- **Highlights**: `ai_find_highlights` (job kind `highlights`) sends the timeline transcript and stores validated `Project.highlights` (timeline time, 10–180 s, at most 10), drawn as bands on the timeline. `relayout` drops any that no longer fit; they are not shifted by edits, so find again after restructuring.
- **Edit plan**: each highlight lists its steps (keep / cut / fades) to follow by hand; **Export short** (`store.exportRange`) selects the highlight's span and opens the Export dialog on it, so the rendered file is just that section. The Rust `highlight_apply` → `ai::short::build_short` command (a sibling 9:16 `.forgevideo`) still exists and is tested but has no button in the UI.
- **Editing captions**: double-click a caption on the timeline, or select the CC track and click a line in the Inspector's Captions list (`cue-row` / `cue-edit`): Enter or blur commits through `cue_set_text`, Escape cancels, blank removes the cue; the time column seeks. Both editors keep the draft in component state (`editingCue: { id, text }` + `v-model`), never `:value="c.text"`: a re-render from the click-away scrub or seek would reset a bound value and lose the edit.
- AI jobs finish with `job://done` carrying `{ project }`; export jobs with `{ destination, strategy, captions }`. The store subscribes on first use (`listenAi`).

Not in V1 (do not add unless Nina reopens): recording (mic/camera/screen — `src-tauri/src/capture/` is a placeholder for Phase 3), proxies, burned-in captions (they stay `.srt`), text auto-wrap, transitions on overlay layers, ffmpeg-next bindings, Metal.

## Layout

- `src/api/tauri.ts` is the **only** place that calls Rust. The UI never builds an ffmpeg argument.
- `src/types/project.ts` hand-mirrors `src-tauri/src/project/model.rs` — change both.
- `src/stores/project.ts` (Pinia) replaces its whole `Project` with what every mutating command returns.
- `src-tauri/src/`: `project` model + JSON persistence · `timeline` pure edit ops (`relayout` is the invariant keeper) · `media` ffprobe → `MediaInfo` · `render` planner (stream copy vs encode) + `graph` (filter_complex argv) + `ffmpeg` (spawn, progress, cancel) · `cache` thumbs/waveforms · `ai` transcribe (whisper) + captions + highlights (Claude Code) + short builder · `jobs` cancel registry + `job://*` events · `commands` thin `#[tauri::command]` layer.
- `src-tauri/vendor/wry/` is wry 0.57.0 with one guard in `src/wkwebview/drag_drop.rs` (upstream panics on drags that advertise filenames but carry none). Wired via `[patch.crates-io]`; drop it when upstream fixes the unwrap.

## Conventions

- Times are integer ms (`Ms`); rationals for fps; ffmpeg gets `ms_to_secs` strings (`1.250`).
- Every Rust op must leave the project valid: call `timeline::relayout` after any structural change.
- Tests: pure functions get direct unit tests; commands are exercised through `tauri::test::mock_app`; anything that spawns ffmpeg uses `tests/fixtures/` (`clip_a_720p.mp4`, `clip_b_1080p.mp4`, `music.m4a`). `whisper-cli` and `claude` are never run by tests: `ai::test_support::script` writes a stand-in shell script. Frontend tests mock `src/api/tauri.ts` via `src/test/fixtures.ts` (`mockApi`, `resolveWith`) and stub browser APIs in `src/test/setup.ts`.
- Do not commit unless asked. Keep the app tiny; prefer removing options to adding them.
